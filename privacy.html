Privacy Policy

Last updated: 21 November 2026

Data the tool uses

  • TikTok access and refresh tokens for the operator's own account, obtained through TikTok Login Kit with the scopes user.info.basic and video.upload.
  • Basic account info returned by TikTok (open_id), used only to confirm which account is connected.
  • Video files created by the operator, uploaded to the operator's TikTok inbox as drafts.

How it is stored

Tokens are stored only on the operator's own computer, in a file readable only by the operator. They are never sent anywhere except to TikTok's official API endpoints. There is no server, database, analytics or tracking.

Sharing

No data is sold, shared with third parties or used for advertising.

Other people's data

The tool does not access, collect or process data of any TikTok user other than the operator.

Deletion

The operator can revoke access at any time in TikTok settings (Security › Manage app permissions) and delete the locally stored token file.
